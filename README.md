# dnSpy Web

Браузерный просмотрщик дампов Il2CppDumper (`dump.cs`) в стиле dnSpy. Работает целиком в браузере, без сервера: файл никуда не отправляется.

## Запуск

Откройте `index.html` в браузере (можно прямо с диска) или выложите папку на любой статический хостинг, например GitHub Pages. Затем перетащите `dump.cs` в окно или нажмите «Открыть…».

## Возможности

- Assembly Explorer: дамп → сборки (`// Image N: X.dll`) → пространства имён → типы → вложенные типы, Base Type and Interfaces, Derived Types, конструкторы, методы, поля, константы.
- Код типа во вкладках с подсветкой, номерами строк исходного файла и комментариями RVA / Offset / VA. Клик по имени типа в коде переходит к нему, Ctrl+клик открывает в новой вкладке.
- Поиск (Ctrl+Shift+K) по типам и членам, в том числе `Type.Member`, и по адресу: точное совпадение RVA / Offset / VA или метод, внутри которого лежит адрес.
- Назад / вперёд (Alt+← / Alt+→, кнопки мыши), несколько дампов одновременно, скрытие блоков GenericInstMethod.
- Разбор в Web Worker и виртуальная прокрутка: дамп на 16 МБ / 450 тыс. строк открывается примерно за секунду.

## Файлы

- `parser.js` — разбор формата Il2CppDumper.
- `app.js` — интерфейс: дерево, вкладки, просмотр кода, поиск.
- `style.css`, `index.html` — разметка и тёмная тема.
